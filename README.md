# Post-Quantum Cryptography Web App

This project demonstrates the use of Post-Quantum Cryptography (PQC) techniques for secure encryption and decryption of data. It integrates a PQC algorithm and provides a user-friendly web interface for key generation, encryption, and decryption operations.

## Features

- **Key Generation**: Generate public and private keys.
- **Message Encryption**: Encrypt a message using the recipient's public key.
- **Message Decryption**: Decrypt a message using the private key and sender's ephemeral public key.
- **User Interface**: Built with Gradio for seamless user interaction.
- **Security Practices**: Implements secure key exchange and safe string handling.
